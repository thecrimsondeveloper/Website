# CAPTURE VIEWS

Default responsive views:
- desktop
- tablet
- mobile

For each requested view:
1. Set the configured viewport.
2. Load or reset the application to the intended state.
3. Wait for readiness.
4. Capture the viewport or full page as requested.
5. Verify the image is non-empty and represents the actual application.
6. Add the capture to the contact sheet when multiple views are requested.

# PREPARE ENVIRONMENT

1. Read the matching file in `../environments/`.
2. Verify Node and package manager.
3. Locate Chromium/Chrome.
4. Inspect Vulkan/Mesa availability.
5. Locate Lavapipe ICD when software rendering is required.
6. Configure environment variables.
7. Install only the dependencies needed by `headless-run-kit` and the target application.
8. Write environment evidence before rendering.

# OPERATE WEBSITE

Operate the real application one action at a time.

Supported operation classes include:
- click/navigation
- scroll
- hover
- drag/pointer input
- keyboard input
- touch emulation
- game start/pause controls
- waits/transitions
- canvas interaction

For every meaningful interaction:
1. Capture the initial state when useful.
2. Perform one controlled action.
3. Observe the resulting state.
4. Record errors or failed transitions.
5. Capture before/after evidence when the state change is part of acceptance.

Use `../guides/OPERATING-GUIDE.md`.

# OPERATING GUIDE

1. Load naturally.
2. Wait for the documented ready condition.
3. Observe the initial state.
4. Interact one action at a time.
5. Verify each state transition before continuing.
6. Capture before/after states when useful.
7. Record console/network/runtime failures.
8. Do not invent expected behavior.
9. Reset state between scenarios when interactions are not independent.

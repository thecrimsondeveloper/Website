# VIEWING GUIDE

Inspect the rendered application for:
- clipping and overflow
- incorrect canvas dimensions
- missing textures/models
- broken layout or stacking
- text overlap/truncation
- responsive regressions
- blank/black WebGL canvas
- wrong camera framing
- shader/material artifacts
- missing fallback states
- loading overlays that never clear

Observe first; do not infer expected visuals that are not supported by the repository or task.

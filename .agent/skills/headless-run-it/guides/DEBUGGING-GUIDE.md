# DEBUGGING GUIDE

Debug from evidence in this order:
1. repository acquisition/missing files
2. dependency/build failure
3. localhost/server failure
4. browser launch/navigation failure
5. network/resource failures
6. JavaScript/runtime errors
7. WebGL/context/renderer failure
8. scene readiness
9. visual/layout defects

Fix or report the actual failing layer. Do not bypass it with a reconstruction.
